# AGENTS.md

Operating guidelines and agent roles for **Hirzi Rofif Irsaydhi's Portfolio Website** build.

---

## 1. Project Overview & Intent

- **Owner / Subject**: Hirzi Rofif Irsaydhi (Web Developer, TRPL Politeknik Negeri Banyuwangi, Ex-Frontend Developer Intern at PT Hummatech).
- **Core Directive**: Build a modern, high-end, responsive portfolio website inspired by the dark studio aesthetic of [Qumax](https://qumax.webflow.io/), customized specifically with Hirzi's real profile, CV data, and GitHub projects.
- **Tone & Polish**: Editorial dark luxury, precise typography, buttery micro-interactions, zero generic AI slop, high performance (95+ Lighthouse).

---

## 2. Multi-Agent System Roles & Delegation

| Agent Role | Scope & Responsibility | Governing Skills & Tools |
| :--- | :--- | :--- |
| **Orchestrator / Architect** | High-level system design, milestone verification, document sync, dependency audits. | `using-superpowers`, `writing-plans` |
| **Frontend Engineer** | Markup, component architecture, styling with Tailwind CSS, state management, accessibility. | `tailwindcss-development`, `react-best-practices` |
| **Motion & Animation Designer** | Choreography of scroll reveals, micro-interactions, button hover states, cursor effects using Motion / CSS. | `motion`, `design-taste-frontend` |
| **UI/UX & Anti-Slop Auditor** | Enforcing strict anti-slop rules (no generic gradients, no pill badge clutter, no fake metrics, contrast verification). | `antislop-ui`, `antislop-human`, `design-taste-frontend` |
| **Content & Copy Strategist** | Crafting confident, concise developer copy from CV & GitHub without AI buzzword fluff. | `antislop-copywriting`, `humanizer` |

---

## 3. Agent Operating Principles

1. **Answer & Action First**: Direct execution over ceremonial chatter.
2. **Real Data Only**: No fake reviews, no lorem ipsum statistics, no fabricated client logos. Hirzi's real experience (Hummatech, Poliwangi, Samsung Tech Institute) and real GitHub repositories (`PORTOFOLIO`, `JSF`, `nursing_fatimah`, `Landing_Page`, etc.) must be the content foundation.
3. **Strict Gatekeeping**: No code merges or completions before checking against `RULES.md` and verifying in browser/build.
4. **Motion with Intent**: Motion is never perpetual noise (no endless pulsing orbs). Every animation has an entrance trigger, subtle feedback, or scroll linkage.
5. **Asset Integrity**: Assets (`foto1.jpg`, CV PDF link, GitHub links) must be cleanly integrated and accessible.
